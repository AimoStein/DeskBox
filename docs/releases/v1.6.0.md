## 更新内容

- 新增独立圆形启动面板。单按并松开 Win 键、左键点击任务栏的开始按钮或双击托盘图标即可打开。Win 键与开始按钮可分别在设置中关闭接管，Ctrl+Esc 可打开 Windows 原生开始菜单。
- 各分组独立成扇区，快捷方式从圆心向外排列在共用的同心环上。打开次数多的项目靠近圆心，次数相同按名称排序。点击圆心搜索，未分组项目显示在底栏。
- 支持拖拽归组和移出分组。右键可分别定位程序或文件、定位快捷方式，以及将快捷方式移入回收站。简桌会自动刷新快捷方式列表。
- 桌面图标收起后，桌面上方居中显示时分秒、日期和星期。双击桌面空白处可隐藏或显示任务栏。
- 面板采用外缘渐隐的纯色渐变。从面板打开设置时，右侧可实时预览背景亮度、色调和饱和度。旧版桌面格子可通过 `--desktop-boxes` 启动。

## 下载与升级

下载 `DeskBox.exe` 即可在 Windows x64 上运行，无需安装 .NET。已有在线更新功能的版本可通过「设置 → 版本更新」升级，也可以退出简桌后用新版 exe 覆盖原文件。升级保留配置和分组数据。

`update.json` 用于客户端检查更新，`SHA256SUMS.txt` 提供程序的 SHA-256 校验值。
