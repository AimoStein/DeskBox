## 更新内容

- 设置窗口改为深灰纯色背景、左侧导航和圆角卡片，保留自动保存。
- 支持自动检查新版本、一键下载、校验并重启更新；检查不使用 GitHub REST API，无需 Token。
- 在线更新保留配置和盒子文件，并备份旧版程序。
- 包含此前的玻璃服务自动恢复、桌面目录迁移恢复和网页快捷方式图标修复。

## 下载与升级

下载 `DeskBox.exe`，Windows x64 单文件绿色版，无需另装 .NET 运行时。

旧版首次升级：退出程序，用新版 exe 覆盖原文件，配置与盒子文件保留。1.5.1 及以上版本也可在「设置 → 更新」中下载更新。

`update.json` 用于客户端检查更新，`SHA256SUMS.txt` 提供程序的 SHA-256 校验值。
